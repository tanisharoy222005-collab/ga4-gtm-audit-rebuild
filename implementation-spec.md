# Analytics Implementation Specification

## Homepage CTA

Event Name:

cta_click

Parameters:

- cta_text
- page_location
- traffic_source

Trigger:

Click Element contains "Get Started"

---

## Lead Form

Event Name:

generate_lead

Parameters:

- form_name
- source
- medium

Trigger:

Successful form submission
