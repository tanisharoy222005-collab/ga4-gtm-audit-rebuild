# GA4 + GTM Audit Rebuild

A portfolio project demonstrating:

- Google Analytics 4 Auditing
- Google Tag Manager Configuration
- Measurement Planning
- Event Taxonomy Design
- Analytics QA Validation

## Repository Structure

```text
src/
```
